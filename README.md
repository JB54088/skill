# Skill Productizer

Skill Productizer 把一段工作流程、SOP、代码仓库或零散需求，整理成可复用、可验证的 AI Skill。

## 它能做什么

- 识别 Skill 的目标用户、触发场景和明确边界
- 从实际文件中提取可靠的输入、输出和业务约束
- 生成结构清晰的 `SKILL.md`
- 把复杂流程拆成可执行步骤、异常处理和停止条件
- 检查占位内容、重复说明、虚构事实、越权操作和敏感信息泄露
- 在需要时把大段模式、数据结构或供应商细节拆到 `references/`

## 适用场景

- 把团队 SOP 产品化成 AI Skill
- 从已有代码仓库整理开发工作 Skill
- 改进一个已有 Skill 的触发范围、输出格式和安全边界
- 为内部流程创建可复用的 AI 操作规范

## 输入

可以提供工作说明、项目仓库、文档、示例输入输出或现有 `SKILL.md`。如果没有给出业务方向，Skill 会先要求补充目的；不会把空仓库伪装成完成品。

## 输出

默认输出一个根目录 `SKILL.md`，必要时附带聚焦的 `references/` 文档，并说明：

1. Skill 做什么、不做什么
2. 需要哪些输入
3. 如何执行
4. 应输出什么结果
5. 哪些情况需要停止或请求确认
6. 如何验证结果

## 使用示例

> 把 `docs/release-process.md` 整理成一个发布检查 Skill，要求包含回滚条件和审批边界。

> 审查这个 `SKILL.md`，找出触发范围过宽、输出不明确和可能越权的地方。

> 根据这个 API 仓库生成一个只读的数据排查 Skill，不允许修改生产数据。

## 文件

- `SKILL.md`：给 AI Agent 使用的正式指令
- `README.md`：给人阅读的功能说明
